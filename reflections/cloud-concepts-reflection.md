# Cloud Concepts Reflection

Cloud computing has become part of my everyday life because many of the applications I use rely on cloud services. One of the services I frequently use is Google Drive. It is classified as Software as a Service (SaaS) because it provides online storage and document management without requiring users to install or manage the underlying infrastructure. It uses a Public Cloud deployment model since it is available to anyone with a Google account.

Another cloud service I use is Facebook Messenger. It is also a SaaS application because it allows users to send messages, make voice and video calls, and share files through the internet. Messenger operates on a Public Cloud since millions of users access the service through Meta's cloud infrastructure.

The third application I regularly use is Canva. Canva is a SaaS platform because it provides online graphic design tools through a web browser without requiring installation of professional design software. Like the previous services, Canva mainly uses a Public Cloud deployment model because it is available to users worldwide.

Version control is an essential part of cloud computing because cloud projects are often developed by multiple people at the same time. Git and GitHub make collaboration easier by recording every change made to files, allowing developers to review previous versions and restore them if necessary. GitHub also supports teamwork through branches, pull requests, and version history, reducing the risk of accidental overwriting or loss of important work. By using GitHub, developers can collaborate more efficiently while maintaining organized and reliable cloud-based projects.
